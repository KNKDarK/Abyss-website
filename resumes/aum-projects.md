# Thirunagari Aum Namaha — Projects

## Speech X Text — Multilingual STT
Full-stack multilingual Speech-to-Text inference pipeline for high-accuracy transcriptions. Built with Python, FastAPI backend for audio processing, and a glassmorphism frontend for seamless user interaction.

## Tim The Time Manager — Browser Extension
Lightweight productivity extension that injects contextual time metrics into the browser DOM. Built with JavaScript and Chrome Extension API with optimized background scripts for zero performance impact.

## Expense Tracker & Analytics Tool
JavaScript-based expense tracking application with data visualization for spending patterns. Features persistent local storage, category management, and intuitive dashboards.

## Image Processing Utility Suite
Desktop-based tools for image-to-PDF conversion, watermarking, and enhancement using Python, OpenCV, and Tkinter. User-friendly GUI for non-technical users.

## Real-Time Chat Application
Browser-based real-time chat with instant message exchange, dynamic interfaces, and event-driven interactions using JavaScript and WebSocket technologies.

## Weather Forecast Web Application
Responsive weather app with real-time updates based on location/search. Integrated third-party weather APIs with error handling and asynchronous data fetching.

## SmartLibraryManagement System
Web-based library management system for book inventory, user records, and issue/return workflows. Role-based access with form validation and structured data storage using Python and database integration.
